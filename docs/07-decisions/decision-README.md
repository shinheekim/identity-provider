# decisions
- 결정 내린 내용 요약
- ADR : Architecture Decision Record 
  - 하지만 주로 시스템 논의 문서
    - ADR 논의 대상
      - 변경 가능성 있는 것
      - 논쟁 가능성 있는 것
      - 나중에 “왜 이렇게 했지?” 나올 것
    - ADR 안 써도 되는 것
     - 단순 CRUD API
     - 명확한 선택 (논쟁 없음)
     - 사소한 코드 변경

### 예시 
```md
# ADR-001 제목

## 상태
결정 필요 / 결정중 / 완료

## 배경
왜 이 문제가 발생했는지

## 결정
무엇을 선택했는지

## 이유
왜 이걸 선택했는지

## 대안
고려했던 다른 방법들

## 영향
이 결정으로 인해 바뀌는 것
```
