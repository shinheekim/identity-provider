# ADR-001 JWT 기반 인증 채택

## 상태
완료

## 배경
인증 서버 설계 시 세션 기반 인증과 JWT 기반 인증 중 선택이 필요했다.  
서비스 확장성과 서버 상태 관리 부담을 고려해야 했다.

---

## 결정
JWT(Json Web Token) 기반 인증 방식을 채택한다.

---

## 이유

- Stateless 구조로 서버 확장에 유리
- 서버에서 세션 저장소를 관리하지 않아도 됨
- API 기반 서비스와의 궁합이 좋음
- 인증 서버와 서비스 서버 간 결합도를 낮출 수 있음

---

## 대안

### 1. 세션 기반 인증
- 서버에서 상태 관리 필요 (DB/Redis)
- 확장 시 세션 공유 문제 발생

---

## 영향

- Access Token / Refresh Token 구조 필요
- 토큰 만료 및 재발급 정책 필요
- 로그아웃 시 토큰 무효화 전략 필요
